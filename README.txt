100 DAY GRIND — PHONE-FRIENDLY 100-DAY TASK TRACKER

FILES
- index.html: website (open directly for checklist and data storage)
- app.js: schedule, checkboxes, reminders, export/import
- manifest.webmanifest / sw.js / icon.svg: installable progressive web app

RUNNING THE WEBSITE
For a quick preview: open index.html in a modern browser.
For installing on your phone and allowing browser notifications, deploy the entire folder to an HTTPS static web host, such as Netlify Drop, GitHub Pages or Cloudflare Pages. The website uses no API keys or backend.
On Android Chrome, select Add to Home screen / Install app; on iPhone Safari, Share > Add to Home Screen.

PHONE NOTIFICATIONS
The "Enable alerts" button requests notification permission. In-browser task alerts only work while the webpage is active; mobile operating systems often suspend inactive webpages.
For dependable phone reminders with the app closed, click "Phone reminders" to download the .ics calendar file, import it to Google Calendar / Apple Calendar, and allow your calendar app's notifications. Importing thousands of events depends on your calendar provider. If your calendar ignores .ics VALARM reminders, set a default event notification in the calendar app. Re-import if you change tasks or dates; avoid importing repeatedly without deleting prior entries to prevent duplicates.

DATA
All checkmarks and custom tasks save to localStorage on the same browser/device. Use Backup and Restore to migrate them. Different devices do not synchronize automatically.

SCHEDULE
This is a direct transcription of the supplied weekly timetable. Monday and Saturday: fasting at breakfast and Lunch - Fruits. Tuesday and Friday: hair care oil; other weekdays serum except Sunday, which says Hair Care. All entries repeat on their respective weekdays. The GATE sessions and gym are modeled as a single checkbox at their start, with the end time shown in the title. No tasks have been changed for health or safety.
